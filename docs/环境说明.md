## 2. 端口

|---|---:|---|
| 前端开发服务 | 5173 | `frontend/.env` |
| 后端 API | 8080 | `SERVER_PORT` 或 `backend/src/main/resources/application.yml` |
| MySQL | 3306 | `DB_PORT` |

## 3. 环境变量

| 变量 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `DB_HOST` | 否 | `localhost` | MySQL 地址 |
| `DB_PORT` | 否 | `3306` | MySQL 端口 |
| `DB_USER` | 否 | `root` | 数据库用户 |
| `DB_PASSWORD` | 是 | 空 | 数据库密码 |
| `DB_NAME` | 否 | `manage_system` | 数据库名 |
| `JWT_SECRET` | 是 | 无 | 至少32字节的 JWT 签名密钥 |
| `JWT_ACCESS_MINUTES` | 否 | `120` | 访问令牌有效分钟数 |
| `JWT_REFRESH_DAYS` | 否 | `7` | 刷新令牌有效天数 |
| `FILE_STORAGE_ROOT` | 否 | `${user.dir}/data/files` | 文件管理的本地存储绝对路径或相对工作目录路径 |
| `AVATAR_STORAGE_ROOT` | 否 | `${user.dir}/data/avatars` | 用户头像的本地持久化目录 |

`backend/.env.example` 是字段说明文件，Spring Boot 不会自动读取 `.env`。本地使用 PowerShell
环境变量，生产环境使用服务器或容器密钥管理。
