# 更新日志

## 1.1.1 - 2026-10-05

### 修复

- 菜单弹窗把未填写字段以空串提交，`route_name` 唯一索引导致新增第二个按钮时报 500；后端统一把空值写为 NULL，并新增 V8 迁移清理历史空串。
- 角色菜单授权弹窗回填时父节点级联勾选全部子菜单，再次保存会多授权；改为严格模式，并使用完整菜单树作为数据源。
- 编辑用户的任何字段都会撤销该用户的登录会话；现在只有账号、状态、密码、角色变化才撤销。
- 用户管理保存时会用弹窗打开时的旧头像地址覆盖用户新上传的头像；头像改为只能由本人在个人中心修改。
- 内置管理员角色比较依赖列表顺序；管理员可以在用户管理中停用自己。
- 编辑已发布公告或重复发布会重置首次发布人和发布时间。
- 文件下载遇到“文件已被移除”等业务错误时，把错误 JSON 当成文件保存。
- 后端不可用时无法退出登录；锁屏页返回登录未撤销服务端会话。
- 生产构建的登录页仍自动填充默认超级管理员账号和密码。
- 缺少上传文件、请求体类型错误被归为 500 系统错误并记录错误堆栈，现返回 400。
- 上传失败时文件清理异常会覆盖原始错误；文件上传成功回调触发两次。
- 消息接收人只能在前 100 个用户中选择，改为按关键字远程搜索。
- 菜单编辑时排序 0 被改成 10；确认框取消和接口失败产生未处理的 Promise 拒绝；删除失败重复提示。
- `sql/手动初始化数据库.sql` 仍要求手动执行 V1、V2，与 Flyway 冲突。

### 安全加固

- 登录增加失败限流：同一账号在同一来源地址 15 分钟内失败 5 次后暂时锁定，返回 429。
- 超级管理员菜单不再依赖角色菜单授权，避免误取消“角色管理”后无法恢复；不再接受对 `R_SUPER` 单独授权菜单。
- 菜单路由名称创建后不可修改（后端权限串依赖该名称）；按钮必须挂在菜单下且同一菜单下权限标识不重复；外链只允许 http/https；各字段长度在参数校验阶段拦截。
- 管理员设置的密码与个人中心规则一致，需同时包含字母和数字。
- 指定接收人发送消息单次最多 500 人；Flyway 不再自动基线非空库。

### 性能

- 用户列表的角色信息改为批量查询，不再逐行查库。

## 1.1.0 - 2026-09-14

- 按业务模块校验后端操作权限，保留超级管理员的授权管理边界。
- 接入前端并发401刷新，修复编辑用户空密码校验以及公告和个人资料清空字段未落库。
- 明确逻辑删除后的名称保留策略，关闭默认SQL日志，记录日志清空操作并修复编码查询参数脱敏。
- 完善文件内容校验、流关闭和事务回滚/提交后清理。
- 增加隔离数据库接口集成测试、文件安全回归和前端会话测试。


## 1.0.0 - 2026-08-11

### 新增

- 集成 Art Design Pro 前端基础框架并切换后端动态菜单模式。
- 新增 Spring Boot + MyBatis-Plus + MySQL 后端工程。
- 新增 Spring Security JWT 登录、刷新令牌和当前用户接口。
- 新增用户、角色、角色授权、菜单和按钮权限 CRUD。
- 新增 Flyway 表结构和初始数据迁移。
- 新增统一响应、参数校验、业务异常和权限控制。
- 新增个人中心真实数据模块，支持查看和编辑个人资料、修改登录密码及角色信息展示。
- 新增个人资料查询、更新和密码修改接口，并通过后端认证上下文限制为当前登录用户。
- 新增 Flyway V3 迁移，补充姓名、地址、个人简介字段和个人中心隐藏路由。
- 新增公告管理模块，支持分页筛选、新增、编辑、发布、撤回、置顶和逻辑删除。
- 新增公告管理后端接口、公告状态记录、发布人及发布时间追踪。
- 新增 Flyway V4 迁移，创建公告表、公告管理动态菜单、按钮权限和模板公告。
- 新增操作日志模块，自动采集后端写操作，支持脱敏、筛选、单条删除和清空。
- 新增文件管理模块，支持白名单上传、分页查询、下载、物理删除和存储路径隔离。
- 新增消息通知模块，支持全部/指定用户发送、个人收件箱、未读统计和已读状态管理。
- 新增顶部真实消息下拉、未读红点、最近消息和全部已读入口。
- 新增个人头像文件上传、格式与文件头校验、安全访问和旧头像清理能力。
- 新增登录成功与失败审计，和操作日志写入同一张表并支持类型筛选。
- 新增统一错误类体系、稳定错误码和错误编号，覆盖参数、认证、授权、业务、资源、文件、数据库和未知系统异常。
- 新增 Flyway V6 迁移，为日志表增加 `OPERATION`、`LOGIN` 类型并将菜单更名为“日志管理”。
- 新增 Flyway V5 迁移，创建日志、文件、消息和消息接收表，并配置动态菜单及角色权限。
- 新增中文需求、设计、数据库、接口、测试、部署和用户文档。

### 变更

- 前端 API 从 Apifox Mock 切换为本地 Spring Boot 服务。
- 初始前端权限模式从 `frontend` 调整为 `backend`。
- 前端开发服务端口调整为 `5173`。
- 完善中英文切换：覆盖登录、系统名称、页面标题、工作台、个人中心及用户、角色、菜单、公告管理页面。
