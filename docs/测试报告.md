### 核心场景

- 普通管理员不能修改超级管理员或新增超级管理员；取消按钮后接口拒绝操作。
- 自定义只读用户角色可查询但不能新增用户；消息角色可选择接收人但不能查询用户管理资料。
- 停用、改密、退出和用户名复用后旧令牌失效；退出不影响其他独立设备会话。
- 刷新令牌单次使用；并发刷新只有一个请求成功；旧实体不能覆盖已递增会话版本。
- 只有新增公告权限时不能直接发布；日志清空操作保留后续审计记录。
- 编辑用户不改密码可提交，短密码仍拒绝；公告撤回的发布字段与用户资料NULL值实际落库。
- 数据库失败时保留旧头像并清理新文件；旧文件只在提交后清理；伪造扩展名、二进制文本和不完整Office容器被拒绝。

### 复跑命令

在项目根目录使用PowerShell：

```powershell
mvn -f backend/pom.xml test package
pnpm --dir frontend test
pnpm --dir frontend lint
pnpm --dir frontend build
```

MySQL专项需预先启动专用临时实例（仅监听127.0.0.1:33178），创建空库manage_system_test_isolated。该模式使用临时实例的root空密码，测试会清理该专用库的表，不能接入业务环境。准备完成后，在项目根目录执行：

```powershell
mvn -f backend/pom.xml '-Dintegration.mysql=true' '-Dtest=SecurityFlowTest' test
```

## 2. 单元测试覆盖点

- 访问令牌生成、用户名解析、令牌类型和有效性验证。
- JWT 密钥长度不足时拒绝启动。
- 文档中的初始密码与种子数据 BCrypt 哈希匹配。
- 个人资料更新会返回合并后的资料和角色信息。
- 头像上传会校验 2MB 上限、MIME、扩展名和文件头，并在更新后清理旧的受管头像。
- 当前密码错误时拒绝修改；正确修改时使用 BCrypt 写入新密码哈希。
- 已发布公告创建时记录发布人和发布时间。
- 已发布公告撤回草稿时清空发布信息。
- 操作不存在公告时返回明确业务错误。
- 写操作自动记录审计日志，敏感查询参数使用 `***` 脱敏，读取接口不记录。
- 登录成功和失败均记录为 `LOGIN` 类型，不依赖认证主体且不保存密码或登录请求正文。
- 文件上传会随机化存储名、规范化原始文件名并拒绝可执行内容类型。
- 删除文件时同步移除数据库元数据和存储根目录内的物理文件。
- 消息发送会去重接收人并拒绝停用账号，已读操作只能修改当前用户的接收记录。
