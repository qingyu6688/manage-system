# 用户使用手册

## 1. 登录

打开前端地址，选择预置账号或手动输入用户名、密码，完成滑块验证后登录。

## 2. 个人中心

1. 登录后点击右上角头像，在下拉菜单中进入“个人中心”。
2. “账号信息”展示登录账号、邮箱、手机号、加入时间和当前角色；这些信息来自当前登录用户的真实数据。
3. 点击左侧个人资料卡中的头像选择 JPG、PNG 或 WebP 图片，单个文件不能超过 2MB；选择后头像会立即上传并同步到顶部用户菜单，右侧基本设置不再重复显示头像上传项。
4. 在“基本设置”中点击“编辑”，可修改姓名、昵称、性别、邮箱、手机和个人介绍；个人中心不采集联系地址。
5. 点击“取消”会恢复本次编辑前的文字资料；点击“保存”后立即更新当前用户资料和顶部用户信息。
6. 在“更改密码”中填写当前密码和两次新密码。新密码需为 8 到 64 个字符，并同时包含字母和数字。
7. 密码修改成功后系统会退出当前会话，需要使用新密码重新登录。

头像上传后立即保存，不受文字资料“取消”按钮影响。

## 3. 用户管理

1. 在“系统管理 → 用户管理”查询用户。
2. 点击“新增用户”，填写用户名、昵称、初始密码、联系方式、状态和角色。
3. 编辑用户时密码可以留空；留空不会修改原密码。
4. 注销用户前系统会二次确认。内置超级管理员不能注销。

## 4. 角色管理

1. 在“系统管理 → 角色管理”维护角色名称、编码、描述和状态。
2. 角色编码使用大写字母、数字和下划线，例如 `R_AUDITOR`。
3. 点击“菜单权限”，勾选菜单与按钮后保存。
4. 被用户使用的角色不能删除，应先调整用户角色。

## 5. 菜单管理

- 一级菜单路径以 `/` 开头，例如 `/report`。
- 子菜单路径使用相对路径，例如 `daily`。
- 组件路径对应 `frontend/src/views`，例如 `/system/user`。
- 目录菜单可以不填写具体页面组件，但仍需唯一的路由名称和路径。
- 按钮节点必须选择所属菜单并填写权限标识，例如 `add`、`edit`、`delete`。

菜单变更后，已登录会话的动态路由可能仍有缓存，重新登录即可加载最新菜单。

## 6. 公告管理

1. 在“系统管理 → 公告管理”查看公告列表，可按标题、公告类型和发布状态查询。
2. 点击“新增公告”，填写标题、类型、状态和正文；开启“是否置顶”后，该公告会显示在列表前方。
3. 草稿不会记录发布人和发布时间；选择“已发布”保存后，系统自动记录当前操作人和发布时间。
4. 已发布公告可点击“撤回”改回草稿，草稿可点击“发布”快速发布，每次操作都会二次确认。
5. 点击“编辑”可修改公告内容；编辑已发布公告并保存时会更新最近发布时间。
6. 点击“删除”并确认后执行逻辑删除，公告不会再出现在管理列表中。

公告正文当前按纯文本保存，适合作为通用模板使用；富文本、附件和公告阅读回执属于后续扩展。

## 7. 日志管理

1. 超级管理员在“系统管理 → 日志管理”查看日志，页面上方提供“系统日志”和“登录日志”两个横向切换入口。
2. 点击“系统日志”只显示系统操作记录，点击“登录日志”只显示登录记录；切换时保留两类日志各自的筛选和分页状态。
3. 系统日志支持账号、接口路径、请求方法和执行结果筛选，登录日志支持账号和登录结果筛选。
4. 日志记录账号、请求方法、接口路径、脱敏查询参数、状态码、IP、浏览器标识和耗时。
5. 系统不记录请求正文、密码、令牌或上传文件内容；查询参数中的敏感字段会显示为 `***`。
6. “删除”用于清理单条日志，“清空日志”会删除全部审计记录，两项操作均需二次确认。
7. 系统管理员不能访问日志接口，权限限制由后端执行。

## 8. 文件管理

1. 在“系统管理 → 文件管理”按文件名或内容类型查询已上传文件。
2. 点击“上传文件”选择图片、PDF、文本、ZIP 或 Office 文件，单个文件不能超过 20MB。
3. 系统使用随机存储名保存文件，列表仅展示原始文件名、类型、大小、上传人和上传时间。
4. 点击“下载”保存原文件；点击“删除”并确认后，数据库元数据和物理文件会一并移除。
5. 可执行文件和未列入白名单的内容类型会被拒绝，文件路径不能越过配置的存储根目录。

## 9. 消息通知

1. 在“系统管理 → 消息通知”查看当前账号的消息，可按标题、类型和阅读状态筛选。
2. 点击“查看”会打开正文并自动标记已读，也可直接点击“标记已读”或“全部已读”。
3. 顶部通知铃展示未读红点和最近 10 条消息，点击消息后进入消息中心。
4. 管理员点击“发送消息”，可向全部启用用户或指定用户发送系统、提醒、任务三类消息。
5. 每个账号只能读取和修改自己的接收状态；发送权限和消息归属均由后端校验。

## 10. 常见问题

- 登录后提示 401：检查后端是否启动、JWT 密钥是否设置，并清理浏览器旧 Token 后重试。
- 前端接口 502：检查 Nginx `/api/` 代理或开发环境 `localhost:8080`。
- 后端启动失败并提示数据库连接：检查数据库已创建，以及 `DB_PASSWORD` 是否在当前终端设置。
- 后端提示 JWT 密钥不足32字节：生成更长的随机字符串后重新启动。
- 个人中心提示当前密码不正确：确认输入的是当前登录账号的原密码；连续尝试不会修改原密码。
- 看不到公告管理菜单：重新登录以加载最新动态菜单，并确认账号具有超级管理员或系统管理员角色。
- 文件上传提示类型不支持：确认扩展名和内容类型在页面提示范围内，且文件不超过 20MB。
- 顶部未读数量未更新：重新打开通知面板或进入消息通知页面，系统会重新获取实时数量。

## 1.1.0 使用变化

- 升级后需要重新登录。普通使用期间访问令牌过期会自动刷新；整个会话达到期限后需要重新登录。
- 退出登录会撤销当前设备会话。修改密码后所有旧会话失效，其他设备需重新登录。
- 编辑用户时密码留空表示保持原密码；通过用户管理保存账号信息后，该账号的旧会话失效。
- 已注销账号名、已删除角色编码和路由名称保留，不能直接重新创建同名对象。
- 自定义业务角色需要同时授权父目录、页面和需要使用的按钮。角色、菜单、日志管理仍由超级管理员操作。
- 文件删除后物理清理若出现存储故障，由管理员根据日志处理；不能把页面删除成功视为备份文件也已删除。

## 1.1.1 使用变化

- 超级管理员始终看到全部启用菜单，角色列表中不再提供超级管理员的“菜单权限”入口。
- 角色菜单授权：勾选按钮会自动勾上所属菜单；勾选菜单会带上其下按钮，可再单独取消按钮实现只读；取消菜单会同时取消其下按钮。
- 菜单编辑时路由名称不可修改；新增按钮需要选择所属菜单。
- 用户管理不再修改头像，头像由本人在个人中心上传；修改昵称、手机号等不会让对方掉线。
- 连续输错密码 5 次后需等待 15 分钟再试。
- 发送消息选择接收人时输入用户名或昵称即可搜索。
- 退出登录在后端不可用时也会完成本地退出。
